## webm 解码问题修复（调整项 #3）

### 做了什么

浏览器录音产出 webm/opus 格式，libsndfile（soundfile 底层）不支持解码，导致 `Format not recognised` 错误。修复方案：在 ASR 识别前用系统 ffmpeg 把上传音频统一转为 16kHz 单声道 wav。

具体改动：

1. **`backend/app/main.py`**：新增 `_ensure_wav()` 函数 + 在 `asr()` 端点中调用，webm/ogg/m4a/aac/wma 等格式先走 ffmpeg 转码再识别；ffmpeg 失败返回 422 + 明确错误信息；新增临时 wav 文件清理逻辑
2. **`backend/app/routers/score.py`**：同步新增 `_ensure_wav()` + 在 `score()` 端点中调用；`_convert_to_wav()` 改用 ffmpeg 替代 librosa（不再依赖 soundfile 解码 webm）；新增 `subprocess`/`shutil` 导入
3. **`backend/tests/test_asr_webm.py`**（新增）：3 个测试覆盖 `/api/asr` 的 webm 转码路径
4. **`backend/tests/test_score.py`**：新增 `TestScoreWebmTranscode` 类，3 个测试覆盖 `/api/score` 的 webm 转码路径

### 改动文件

| 文件 | 变更 |
|------|------|
| `backend/app/main.py` | 新增 `_ensure_wav()`、`_FFMPEG_ONLY_SUFFIXES`；`asr()` 加 ffmpeg 转码 + wav 临时文件清理 + RuntimeError 处理 |
| `backend/app/routers/score.py` | 新增 `_ensure_wav()`、`_FFMPEG_ONLY_SUFFIXES`；`score()` 加 ffmpeg 转码 + wav 临时文件清理 + RuntimeError 处理；`_convert_to_wav()` 改用 ffmpeg |
| `backend/tests/test_asr_webm.py` | 新增：webm 转码成功/失败/wav 跳过 3 个测试 |
| `backend/tests/test_score.py` | 新增 `TestScoreWebmTranscode` 类 3 个测试 + `MagicMock` 导入 |

## 挑战页「评分中」提示消失 bug 修复

### 做了什么

提交评分按钮的 `v-if` 条件只判断了 `phase === 'recorded'`，点击提交后 phase 变为 `submitting`，按钮瞬间消失，导致用户看不到「评分中…」+ 旋转图标。

修复：将条件从 `phase === 'recorded'` 改为 `phase === 'recorded' || phase === 'submitting'`，使按钮在评分请求期间保持显示。

## TTS 语音合成功能实现（任务 #16）

### 做了什么

实现 TTS 语音合成功能三部分，严格按 API 契约 §1.8 和数据模型 §4 实现：

1. **后端 services/tts_service.py**（新增）：CosyVoice2 语音合成服务封装
   - 懒加载：`is_loaded` 属性判断，`_ensure_loaded()` 触发加载
   - GPU 守卫：`is_gpu_available` 检查 `torch.cuda.is_available()`，无 GPU 时 `load()` 抛 `RuntimeError`
   - 多文件加载：检查 `llm.pt` / `flow.pt` / `hift.pt` 三个模型文件
   - 模型目录：默认 `/home/rat/dialect_asr_system/tts/output/final`，可通过环境变量 `TTS_MODEL_DIR` / `TTS_DEVICE` 配置
   - 线程安全：`_load_lock` + `_infer_lock`，推理串行执行
   - `synthesize(text)` → `(waveform, sample_rate)`：文本→音频波形

2. **后端 routers/tts.py**（新增）：`POST /api/tts` 端点
   - 请求体：`{"text": "今朝天气老好"}`（Pydantic 校验：必填，≤200 字）
   - 响应 200：`{"audio_url": "/data/audio/tts_xxx.wav"}`
   - 响应 503：模型未加载（GPU 不可用等）
   - 响应 400：文本为空/超长；响应 500：合成失败
   - 音频落盘：`backend/data/audio/tts_{ts}.wav`

3. **前端 pages/tts.vue**（重写）：完整 TTS 页面
   - 文本输入框（textarea），实时字数统计 + 超限提示
   - 「合成语音」按钮 + spinner；合成成功后显示 `<audio>` 播放器
   - 复用 `getErrorDetail` 处理后端错误；绿色主题（`emerald-*`）

4. **后端 main.py**（修改）：导入 TTS 服务 + router 注册 + health 增加 `tts_loaded` + lifespan 退出卸载

5. **测试 tests/test_tts.py**（新增）：17 个测试全 mock
   - 模型未加载 503、文本校验 400/422、成功合成 200 + 落盘、合成异常 500、服务层单元测试
