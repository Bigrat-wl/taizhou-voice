## 静态文件服务挂载

### 做了什么

解决遗留问题 #4（`audio_url` 无静态文件服务），在 `backend/app/main.py` 添加 `/data/audio` 静态文件挂载。

### 改动文件

| 文件 | 变更 |
|------|------|
| `backend/app/main.py` | 导入 `StaticFiles`；定义 `AUDIO_DIR` 常量；`mkdir` 确保目录存在；`app.mount("/data/audio", ...)` |

### 验证结果

```bash
cd backend && UV_CACHE_DIR=$PWD/.uv-cache uv run python -c "from app.main import app; print('static mounted')"
# 输出：static mounted

cd backend && UV_CACHE_DIR=$PWD/.uv-cache uv run pytest -v
# 64 passed, 0 failed
```

### 遗留问题

无。静态文件服务已就绪，前端播放 `/data/audio/*.wav` 可正常返回 200。
