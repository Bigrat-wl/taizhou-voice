## 做了什么

### 1. 排行榜页 `leaderboard.vue`（从占位页到完整实现）

- **双 Tab 布局**：正确数榜 / 点赞榜，Tab 切换时懒加载数据
- **正确数榜**（对应 `GET /api/leaderboard/correct`）：
  - 前三名突出显示（金银铜渐变背景 + 大徽章）
  - 展示 rank / nickname / correct_count / total_score / best_score
  - 加载态、错误态、空状态全覆盖
- **点赞数榜**（对应 `GET /api/sentences/{id}/recordings`）：
  - 句子选择器（横向按钮组，从 `GET /api/sentences?n=50` 获取全部句子）
  - 选中句子后加载该句下所有录音，按 like_count 降序
  - **听录音交互**：播放按钮点击后播放 `audio_url`，再点暂停；播放中高亮
  - **点赞交互**：心形按钮，已点赞填充+粉色，未点赞灰色；调用 `POST/DELETE /api/recordings/{id}/like` 幂等切换
  - 未登录时点赞按钮 disabled + title 提示
  - 前三名突出显示，录音列表排名徽章
- 认证：带 token 时 `liked_by_me` 按当前用户算，不带 token 恒为 false（契约一致）

### 2. 挑战赛页 `challenge.vue` 百词斩式重构

- **单句显示**：5 句只显示当前一句（`v-show="idx === currentIndex"`），不再平铺列表
- **结果态**：提交评分后展示大字分数圆形（24×24 圆 + 4xl 字号）+ 颜色档标签 + 识别详情 + 试听回放
- **主按钮「下一句」**：评分完成后主操作按钮推进到下一句
- **最后一句「查看总结」**：最后一句评分后按钮变为「查看总结」
- **总结页**：全部完成后展示总分、平均分（带颜色档）、各句得分概览列表、重新挑战按钮、查看排行榜链接
- **复用现有逻辑**：useRecorder / useBlobUrl / useAuth 状态机完全保留，SentenceState 接口不变
- 进度条改为「第 N / M 句」+「已完成 X · Pct%」
