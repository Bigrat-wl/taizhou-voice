## 各项说明

### 1. 加 CORS
- 现状：`backend/app/main.py` 无 CORSMiddleware
- 影响：前端 Nuxt(3000) 跨域调后端(8000) 会被浏览器拦截
- 方案：加 `fastapi.middleware.cors.CORSMiddleware`，开发期放开来源

### 2. 统一 GPU 部署方案
- 现状：`pyproject.toml` 用 `[tool.uv.sources] torch = { index = "pytorch-cpu" }` 写死 CPU 版
- 影响：`uv sync` 在 GPU 机器上会装 CPU 版 torch
- 方案：README「GPU 场景」明确改 pyproject 删 source 段 + `uv sync --reinstall` 装对应 CUDA 版

### 3. webm 解码验证
- 现状：`_ALLOWED_SUFFIXES` 含 `.webm`，但 librosa 解码 webm 依赖 ffmpeg
- 影响：浏览器 MediaRecorder 默认产出 webm/opus，可能解不了
- 方案：~~前端录音时实测一次，解不了则后端加 ffmpeg 转码兜底~~ → **已修复**：`/api/asr` 和 `/api/score` 端点在 ASR 识别前用 `ffmpeg -y -i <src> -ar 16000 -ac 1 <dest.wav>` 统一转码；`_convert_to_wav()` 也改用 ffmpeg 替代 librosa

### 4. 模型路径迁移
- 现状：默认 `/home/rat/dialect_asr_system/finetune/output/final`（开发机绝对路径）
- 方案：部署前拷到 `models/asr/asr-v1.0/`，改默认值 + 配 `model.yaml`

### 5. GPU 实测
- 游戏本上 `nvidia-smi` → 装对应 CUDA torch → 全功能验证（含 TTS）
